e-plantShopping
Project Overview
e-plantShopping is an e-commerce web application designed for plant lovers to browse, select, and purchase various houseplants and gardening supplies. The application provides a seamless shopping experience with features such as product categorization, a shopping cart, and a responsive layout.

Features
Product Catalog: Browse a wide variety of plants with details, pricing, and images.

Shopping Cart Management: Add or remove items, adjust quantities, and view the total cost.

Responsive User Interface: Built using React for a dynamic and interactive frontend experience.
